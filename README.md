## Project Description
Plant Complainer is a dramatic, hilarious, Malayalam-speaking virtual plant pet living inside your computer. It observes your daily computer activities (coding, gaming, watching YouTube, studying), tracks its own virtual needs (water, sunlight, health, attention, mood), and generates dramatic Malayalam gossips, complaints, and sings Malayalam songs out loud in a high-pitched Talking Tom voice while floating bees and dragonflies fly around your screen!

## The Problem (that doesn't exist)
Computer users get lonely, code without taking breaks, and ignore houseplants. Existing plant reminder apps just send plain boring push notifications that everyone ignores. Nobody was solving the urgent crisis of virtual plants suffering emotional neglect and gossip deprivation while you play games or watch YouTube!

## The Solution (that nobody asked for)
A virtual Malayalam-speaking desktop plant that actively interrupts you, gossips about your laptop obsession, sings classic Malayalam songs in tune, moves to random screen locations, and spawns screen-wide flying bees & zigzag dragonflies so you can never ignore your plant again!

## Technical Details

### Technologies/Components Used

#### For Software:
- **Languages used**: Python 3.13
- **Frameworks used**: PySide6 (Qt for Python GUI & Animation)
- **Libraries used**: Edge-TTS, PyTTSx3, NumPy, FFmpeg (imageio_ffmpeg), Wave, SoundFile, PyDub
- **Tools used**: FFmpeg Audio DSP (Pitch Resynthesis, Vibrato, Equalizer, Chorus Echo), Windows Process Management APIs

#### For Hardware:
- **List main components**: Windows PC / Laptop, Audio Output Speakers, Display Monitor
- **List specifications**: Windows OS, Python 3.13 runtime, FFmpeg binary
- **List tools required**: Keyboard & Mouse (for caring, watering, and triggering song performances)
